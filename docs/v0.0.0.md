# v0.0.0

这是未发布版本的第一版。换言之，就是从零开始搭建的第一个文档。

## 1. 前端

类似 Scratch 风格，但是分为三个标签页：模型、数据处理和训练管线。

### 1.1 主要功能区

#### 1.1.1 模型

主要负责模型类的创建。可以创建多个模型，每个模型都是一个独立的代码块。

*后续考虑添加可视化功能：选择某个模型的代码块时可以可视化出其架构*

#### 1.1.2 数据处理

主要负责产生 Dataset 和 DataLoader。

*后期考虑添加可视化功能：指定数据集后，自动可视化出数据集组织形式、.csv 文件格式等*

#### 1.1.3 训练管线

主要负责使用另外两个模块产生的对象进行训练。包含常见的训练进程监督信号（例如：当前 epoch 数、当前损失率等）以及常用图表（例如：可以选择创建折线图，然后传入 x 轴和 y 轴数据来源）。

*后续考虑添加可视化，主要可视化数据流*

### 1.2 Tutorial

包含基础的人工智能教学，以及对应的可视化。

*后续可能会扩展到在一个完整的人工智能训练流程中，所涉及到的所有基础计算机知识*

### 1.3 其他功能

可选与标准 PyTorch 代码对照，具体方式是：点选到某个代码块时，对应 PyTorch 代码高亮（目前想实现的视觉效果是：在代码底层用表示不同功能的颜色做背景，类似在 VSCode 中查看 git 提交记录时的 “新增” 与 “删除”）。

更多功能在介绍后端逻辑时会带出。

## 2. 后端

### 2.1 代码运行逻辑

将拖拽代码转换成 PyTorch 代码。用户操作拖拽代码，后台实际运行 PyTorch 代码。

### 2.2 硬件环境

不需要用户拖拽代码，自动生成检测 CUDA、选择设备代码。

需要用户提供运行环境，例如 SSH 远程服务器（综合考虑，很难要求远程服务器都装有我们的软件，因此让学生本地运行我们的软件，连接到远程 SSH 比较合理），并且提供简单易懂的配置服务器界面（分成两个部分：一个是纯填空式配置部分，另一个是简单介绍各个字段含义）。

### 2.3 虚拟环境

将常用 python 包进行打包，例如 “机器学习常用包”、“深度学习常用包”、“计算机视觉常用包” 等等。用户不需要知道每个包中有哪些具体的包，也不需要知道如何下载这些包，如何维护虚拟环境。用户只需要点击选择当前包，然后后端会自动在终端中检测是否有 conda、并自动维护虚拟环境。并且也支持单独下载。

前端中显示为：每个包对应一个块，可以展开，展开后包含每个包的简单说明、大小、依赖等基本信息。可以多选，批量下载，也可以挨个下载，也可以整个包一起下载。

*需要注意的是，目前，我的用户还只局限在复旦校内通识课程，因此部分环境配置都以复旦通识教育课程为准。该课程中一般使用远程服务器，且自带 conda 环境*

## 3. 用户主流程

用户依然需要在本地或服务器上准备好已经解压好的数据。这一步往往由老师负责，目前还不打算加入教用户如何自己寻找并下载数据集的内容。

软件启动后，类似 VSCode 开始界面，会指导学生进行初始的配置。目前来说，是：创建一个项目文件夹，里面至少需要一个名字为 `data` 的文件夹，然后把数据集拖进去。

在软件内打开该项目文件，软件会自动检索 data 目录，并设置为环境变量。后续用户在完善数据处理流程时可以直接使用该值。

用户需要在**数据处理**模块中创建一个 DataLoader 和 Dataset 主代码块，以及在**模型**模块中创建一个模型类主代码块。这三类代码块支持**注册**功能。注册后，在训练管线模块中可以找到注册的变量（对的，显然，这三个主代码块都需要命名），并可以拖拽过来完善进一步的逻辑。

> 注册规则（v0.0.0 最小实现）：
> - 每个 Dataset / DataLoader / 模型类主代码块需要用户命名
> - 名字在项目内唯一，重名时报错让用户改
> - 注册后，训练管线的 model / train_loader / test_loader 参数
>  下拉框里出现已注册的名字
> - v0.0.0 每个类型只允许注册一个（不做多模型对比）

要注意的是，比如说，虽然模型类主代码块在模型模块和训练管线模块中都存在，但两个模块中可以调用的对象的接口、行为都不一样。

在训练管线模块中，需要创建一个**训练管线**主代码块，该代码块可以包含：训练、验证、测试以及可视化。单击选中该主代码块，可以运行该代码块，并打印输出。

打印在终端中的输出可以直接由软件前端打印，并且所有输出都在项目文件夹下对应保存，并且将保存的文件与积木链接，让用户知道当前文件对应的是哪一句命令。对于图表类指令，软件可以同时读保存的结果并显示在前端页面上，让用户能实时看到输出。

*进一步的设计：后续可能改变这一块行为，即将训练和可视化分开，训练主代码块可以将记录的结果存入变量中，可视化主代码块调用这些变量进行画图*。

## 4. 积木清单

目前先实现一个最小可行 demo，要求可以实现以下代码：

```python
import torch
from torch import nn
from torchvision import datasets
from torchvision.transforms import transforms
import matplotlib.pyplot as plt

# 设备选择
if torch.cuda.is_available():
    device = torch.device("cuda")
elif getattr(torch.backends, "mps", None) and torch.backends.mps.is_available():
    device = torch.device("mps")
else:
    device = torch.device("cpu")
print("Using device:", device)

# 模型结构
class MnistCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),

            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )

        self.fc = nn.Sequential(
            nn.Linear(32*7*7, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = self.conv(x)
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x
    
# 超参数设置
batch_size = 128
learning_rate = 0.01
epochs = 10

# 数据预处理
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

data_train = datasets.MNIST(root="./data/", train=True, download=True, transform=transform)
data_test = datasets.MNIST(root="./data/", train=False, transform=transform)

# DataLoader（GPU优化）
train_loader = torch.utils.data.DataLoader(
    data_train,
    batch_size=batch_size,
    shuffle=True,
    num_workers=2,
    pin_memory=True
)

test_loader = torch.utils.data.DataLoader(
    data_test,
    batch_size=batch_size,
    shuffle=False,
    num_workers=2,
    pin_memory=True
)

# 模型加载到GPU
model = MnistCNN().to(device)

criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate, momentum=0.9)

# 可视化
for i in range(5):
    plt.subplot(1, 5, i + 1)
    plt.xticks([])
    plt.yticks([])
    plt.imshow(data_train.data[i], cmap='gray')
plt.show()

# 训练
lepoch, lloss, lacc = [], [], []

for epoch in range(epochs):
    model.train()
    total_loss = 0
    total_num = 0

    for x, y in train_loader:
        x = x.to(device)
        y = y.to(device)

        y_pred = model(x)
        loss = criterion(y_pred, y)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * x.size(0)
        total_num += x.size(0)

    epoch_loss = total_loss / total_num

    lepoch.append(epoch+1)
    lloss.append(epoch_loss)

    # 测试
    model.eval()
    correct = 0
    total = 0

    with torch.no_grad():
        for x, y in test_loader:
            x = x.to(device)
            y = y.to(device)

            y_pred = model(x)
            _, pred = torch.max(y_pred, dim=1)

            correct += (pred == y).sum().item()
            total += y.size(0)

    acc = correct / total * 100
    lacc.append(acc)
    print(f"Epoch {epoch+1:02d} | Loss: {epoch_loss:.4f} | Acc: {acc:.2f}%")

print(f"\nFinal Test Accuracy: {lacc[-1]:.2f}%")
    
# 准确率&损失值变化曲线
plt.plot(lepoch, lloss, label='loss')
plt.plot(lepoch, lacc, label='acc')
plt.legend()
plt.show()

# 可视化预测结果
model.eval()

# 取一批测试数据
data_iter = iter(test_loader)
images, labels = next(data_iter)

# 放到GPU
images = images.to(device)
labels = labels.to(device)

# 预测
with torch.no_grad():
    outputs = model(images)
    _, preds = torch.max(outputs, 1)

# 转回CPU用于画图
images = images.cpu()
preds = preds.cpu()
labels = labels.cpu()

# 画图
plt.figure(figsize=(10, 4))

for i in range(10):
    plt.subplot(2, 5, i + 1)
    plt.xticks([])
    plt.yticks([])

    img = images[i].squeeze().numpy()
    plt.imshow(img, cmap='gray')

    pred = preds[i].item()
    true = labels[i].item()

    color = 'green' if pred == true else 'red'
    plt.title(f"Predict:{pred} / Truth:{true}", color=color)

plt.tight_layout()
plt.show()
```

该代码来自于真实复旦通识教育课程案例。

# 积木清单 v0.0.0
#
# 设计原则：
#   1. 积木按 PyTorch / Matplotlib 的通用概念划分，不绑定具体代码
#   2. 分两类：container（容器，有凹槽）/ block（内容，填进凹槽）
#   3. 参数槽里的选项 = 下拉框，不单独做积木

  device:
    imports: [torch]
    code: |
      if torch.cuda.is_available():
          device = torch.device("cuda")
      elif getattr(torch.backends, "mps", None) and torch.backends.mps.is_available():

# ============================================

  # ---- 容器：预处理组合 ----
  - id: data.compose
    type: container
    name: 预处理流水线
    imports: [torchvision.transforms]
    slots:
      - name: steps
        label: 预处理步骤
        accepts: [data.to_tensor, data.normalize]
    output: transform
    code: |
      transforms.Compose([
          {steps}

  # ---- DataLoader ----
  - id: data.dataloader
    type: block
    name: 创建 DataLoader
    imports: [torch.utils.data]
    params:
      - name: dataset
        type: dataset_ref
      - name: batch_size
        type: int
        default: 128
      - name: shuffle
        type: bool
        default: true
    output: dataloader
    code: |
      torch.utils.data.DataLoader(
          {dataset},
          batch_size={batch_size},
          shuffle={shuffle},
          num_workers=2,
          pin_memory=True
      )


# ============================================
# 二、模型
# ============================================
model:
  # ---- 容器：模型类 ----
  - id: model.define
    type: container
    name: 定义模型类
    imports: [torch, torch.nn]
    params:
      - name: class_name
        type: string
        default: MyModel
    slots:
      - name: body
        label: 网络结构
        accepts: [model.conv2d, model.linear, model.relu, model.maxpool2d, model.dropout, model.flatten, model.sequential]

    output: block

          {layers}
      )

  # ---- 内容：层 ----
  - id: model.conv2d

        type: int
      - name: out_channels

代码生成顺序：
1. import 段（从所有积木的 imports 字段收集、去重、排序）
2. 设备检测（globals.device）
3. 数据处理积木（按依赖顺序：compose → dataset → dataloader）
