# Implementation decisions


| ID | 原文情况 | 本计划的明确执行规则 |
| --- | --- | --- |
| D01 | 每类只允许注册一个，但示例有训练和测试各一套 Dataset / DataLoader | 一个项目最多注册 1 个活动模型类、1 个训练 Dataset、1 个测试 Dataset、1 个训练 DataLoader、1 个测试 DataLoader；是“每个角色一个”，不是 Dataset 总共一个。允许存在未注册草稿。 |
| D02 | `transform_ref` 被引用，但正文未定义预处理如何注册 | `data.compose` 增加名称与“供本项目引用”状态，使用同一符号表。v0.0.0 最多 1 个活动 transform，可同时服务训练与测试 Dataset。 |
| D03 | 模型区输出模型类，训练参数写 `model_ref` | 跨标签页引用模型定义的稳定 ID；编译器在训练作用域自动生成一次模型实例并 `.to(device)`。界面写“使用模型”，不要求学生再拼实例化积木。 |
| D04 | 示例启用数据下载，主流程又要求老师提前准备数据 | 所有正式训练默认 `download=False`；缺数据阻止启动，不隐式联网。教师/开发者可以另行准备数据。v0.0.0 不开发数据集下载教学。 |
| D05 | 可视化的数据源写“训练准确率”，示例算的是测试准确率 | 正式字段为 `test_accuracy`，界面显示“测试准确率”。本版本不额外计算训练准确率；迁移旧选项时明确提示更名，不能只改标签而改变数值含义。 |
| D06 | 训练容器只有“每轮结束后”，示例还要求训练前样本和训练后预测图 | 以 `train.loop` 作为唯一训练管线根；保留 `body` 表示每轮结束后，新增 `before`、`after` 两个可视化槽。禁止将全部可视化无条件放到脚本末尾。 |
| D07 | 损失函数列出 CE / MSE / BCE，示例只覆盖十分类 | v0.0.0 的内置数据集都是单标签十分类：CE 可执行；MSE / BCE 在目录中保留但禁用并解释任务不匹配。不得把类别整数标签直接交给 MSE / BCE，也不偷偷转 one-hot 改变教学任务。以后按任务类型扩展。 |
| D08 | DataLoader 示例写死 `num_workers=2, pin_memory=True` | 工程参数不做学生积木：Linux 默认 workers=2，其余平台默认 0；只有 CUDA 启用 pin_memory。设置写进运行快照并展示实际值。开发/测试可显式统一 workers=0。[T4] |
| D09 | 训练示例使用 `plt.show()`，但要在远程无桌面环境运行 | 正式运行用 Agg 后端写 PNG；前端显示文件，不运行阻塞式 `plt.show()`；每次渲染后关闭 figure。[T5] |
| D10 | 示例只展示 MNIST，但积木选项包含 CIFAR10、FashionMNIST | 保留并实现 3 种 Dataset 适配器；MNIST 是全链路主验收。CIFAR10 输入通道、尺寸和 Normalize 参数必须随数据配置验证，不能套用 MNIST 的 `1568`。 |
| D11 | `viz.savefig` 没定义属于哪张图 | 增加 `viz.figure.save` 槽，最多一个 `viz.savefig`；必须从所属 figure 获取引用，禁止依赖 pyplot 的“当前图”。 |
| D12 | “完整 PyTorch 代码”与日志采集存在潜在冲突 | 学习代码中的模型、训练和测试循环保持展开；协议、取消检查与文件写入可引用同目录的标准库辅助文件。导出整个运行代码目录，无需安装 Easy-AI Python 包即可运行。 |
| D13 | 模型体既能放层也能放 Sequential，未定义 forward | 按 body 的连接顺序依次执行；Sequential 生成子模块，Flatten 生成一次张量展平。v0.0.0 不支持分支、残差、多个输入或自动修补尺寸。 |
| D14 | 本地项目和服务器上的 `data` 不是同一个路径 | 保存可移植项目时只保存数据绑定意图；机器相关配置解析成本地或远端的实际绝对路径。教师远程数据优先直接引用；上传本地 data 必须显式触发。 |

D07 是明确的能力限制，而不是遗漏待办。界面、编译校验、文档和测试必须一致，不能出现“能选但必定在运行时崩溃”的选项。
