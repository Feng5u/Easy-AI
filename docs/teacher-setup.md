# 教师准备说明（v0.0.0 开发检查点）

完整课堂版本尚未验收。便携目录目前仅完成 Linux x64 本机布局和独立冻结后端检查；Windows 11 x64 是原计划优先目标，当前原生 CI 仍失败，不能按已支持交付。macOS/MPS 未验。实际支持必须以 release-checklist 的证据为准。

## 已有训练环境与数据

应用后端 Python 不安装 torch。请另准备课程训练 Python：Python 3.11、相容的 torch/torchvision/matplotlib，以及明确的 CPU/GPU；安装、下载、许可由教师按学校范围另行审批。应用不会自动安装 conda、驱动、CUDA 或训练包。现有老师环境只读，不默认升级/降级共享 torch。

真实数据应提前放到受信任目录。MNIST/FashionMNIST 本地入口校验离线 IDX 文件；默认 download=False，不会联网补齐。CIFAR10 虽可编译，当前本地运行预检仍拒绝，不能声称课堂闭环。合成 IDX 测试只证明执行链，不代表 MNIST 学习效果。

本地运行从原生选择器分别选择工程目录、独立训练 Python 和已准备的数据目录。先查看预检结果，再检查编译代码及输出路径，显式开始；正式10 epoch与quick子集分开记录。不要把训练环境、数据、机器绑定或运行结果放进公开仓库。

## SSH

先确定授权的隔离 Linux 目标、账号及测试窗口。通过另一个可信渠道核验主机指纹；应用提示的指纹不能单独作为可信依据。密钥变化需重新核实，不直接替换。当前源码支持密码或明确选择私钥文件；私钥由Main原生选择，不记住路径/口令、不扫描密钥或使用agent，具体格式和KDF限制见private-key-auth.md。凭据只在安全会话使用，不写配置、截图或报告。真实私钥和SSH尚未验；先前7b91c46便携目录不包含本轮新功能。

远端需已有相容训练环境和真实数据。断线不等于远端停止，取消请求接受不等于进程退出；等待应用确认。未确认停止时不要重启同一任务、删锁文件或清理目录。真实 SSH、正式训练、断线/重启恢复和产物映射尚需实际验收。

## 工程、输出与修复

新建/导入选择新目录，不覆盖已有工程。工作区分数据/模型/训练，Python编译器唯一生成代码；代码视图只读。工程JSON导出与完整代码Bundle分开。当前源码可在保存并编译通过后，主动选择父目录导出新easyai-code子目录，含辅助文件、快照及hash清单；不会安装或训练。见code-bundle-export.md；真实训练环境脱离应用运行和原生picker未验，旧便携产物不含新入口。运行前保存并重新编译陈旧快照；只读、冲突或恢复错误时保留原文件，选择新目录副本处理。

出现错误先查看积木定位、生成代码及本地日志；七主题离线教程和数值卷积实验不启动训练。脱敏诊断导出仅固定字段，但原始日志仍可能含本机路径；分享前人工检查。取消/失败保留日志和已有产物，不承诺环境事务回滚。

包管理当前只提供目录/离线计划、确认登记、取消与受控后端基础，生产安装入口关闭。新owned目录的半成品不能作为可用环境；不删除未知目录、不盲解锁。真实conda bootstrap、授权执行接线、活安装重连和未知停止安全解除仍缺。

## 本地产物

构建者先完成 `pnpm build`，再运行 `pnpm package` 和 `pnpm package:verify`。便携目录包含 Electron、冻结 sidecar、教程/本文/验收清单及已有第三方许可材料。项目自身许可证尚未声明，native/system库许可清单仍需核审；它是本地验证产物，不是已批准分发的正式包。入口为 `easyai`，保留原Chromium sandbox且不要改名为electron；不得使用 --no-sandbox、修改系统权限或安装特权 helper 来绕过失败。

目前没有可宣称通过的干净机器/实际桌面课堂结果。启动、编辑、原生对话框、Monaco Worker/CSP、训练和 SSH 等检查均须在合适目标机另做，不能以冻结 HTTP smoke 代替。


显式上传入口（当前源码）：优先直接引用已有远端dataRoot；确需上传时，认证后另选专用本地数据目录，预览源/应用管理目标/数量/字节/预算并明确确认。仅新UUID数据目录，不写教师共享目录，不自动随运行上传；完成后还需重新probe绑定。合成SFTP验证不代表真实SSH成功；历史恢复/补传/Windows等未验，见data-upload.md。旧便携产物不含该入口。
