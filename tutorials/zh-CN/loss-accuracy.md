# loss 与 accuracy

loss 衡量当前预测与目标的差距，供优化器更新参数；accuracy 是预测类别正确的样本比例。它们的数值与单位不同，不能直接相减或用同一纵轴解释。

本版本报告 train_loss（训练损失）和 test_accuracy（测试准确率），不额外计算训练准确率。测试准确率不是验证集准确率，也不能保证模型对未知数据的表现。

内置数据集是单标签十分类，执行交叉熵 CrossEntropy。MSE 与 BCE 在当前任务下禁用，不会把整数标签偷偷改成 one-hot。

图表只显示真实运行记录中的指标。训练还未执行时应显示空状态；本教程的数值卷积不生成任何训练曲线。
