# 设备与运行环境

应用环境运行桌面和编译服务，训练环境运行生成的 PyTorch 代码。二者分离，不能把 torch 装到应用 Python 中来替代训练环境准备。

仅在自动模式（auto）下，生成代码依次检查 CUDA、MPS，均不可用时使用 CPU。已绑定或显式指定的设备不可用时会阻断运行，不会静默回退；请重新检查环境与设备绑定。最终设备和选择原因以本次真实运行记录为准；教程不探测硬件，也不承诺 GPU 一定可用。

本机需要选择已准备好的训练 Python 与数据目录。服务器可以直接引用老师已有环境和数据，本机无需复制；数据不会自动上传。教师共享环境默认只检查，不安装或升级。

环境检查通过、代码检查通过和训练完成是不同的状态。CPU 较慢不等于程序失败；环境缺包时应前往环境设置，而不是随意改模型。
